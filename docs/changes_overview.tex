\section{Summary}
%==========================================================================

This document catalogues \emph{all} modifications on the \texttt{ibm\_gpu}
branch relative to the \texttt{eib\_dev} baseline commit
(\texttt{8666588}).  Changes fall into three categories:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{GPU correctness \& portability} --- fixes for data races,
        CUDA device-code issues, and lambda capture bugs.
  \item \textbf{RZ axisymmetric coordinate support} --- new finite-volume
        divergence, geometric sources, volume-weighted diagnostics.
  \item \textbf{IBM (Immersed Boundary Method) refactor} --- GPStore,
        BVH acceleration, modular file split, moving-geometry support.
\end{enumerate}
