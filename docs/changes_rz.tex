\section{Overview}
%==========================================================================

Cerisse originally supported only Cartesian grids.  The modifications on
branch \texttt{ibm\_gpu} add axisymmetric cylindrical (RZ) coordinate
support by leveraging AMReX's built-in \texttt{Geometry::IsRZ()} flag
(\texttt{geometry.coord\_sys = 1} in the input file).

The RZ convention in Cerisse is:
\begin{itemize}
  \item Direction~0 ($i$) = radial direction $r$, with the symmetry axis at
        $r = 0$ (\texttt{prob\_lo[0] = 0}).
  \item Direction~1 ($j$) = axial direction $z$.
  \item \texttt{AMREX\_SPACEDIM = 2} is required.
\end{itemize}

%==========================================================================
\section{Mathematical Formulation}
%==========================================================================

\subsection{Finite-Volume Divergence}

In cylindrical $(r,z)$ coordinates the conservative finite-volume update
for cell $(i,j)$ is:
\[
  \frac{\partial \mathbf{U}}{\partial t}
  = -\frac{1}{V_{ij}} \left[
      \left(A^r_{i+1/2}\,\mathbf{F}^r_{i+1/2} - A^r_{i-1/2}\,\mathbf{F}^r_{i-1/2}\right)
    + \left(A^z_{j+1/2}\,\mathbf{F}^z_{j+1/2} - A^z_{j-1/2}\,\mathbf{F}^z_{j-1/2}\right)
  \right]
  + \mathbf{S}_{\text{geo}}
\]
where:
\begin{align}
  V_{ij}         &= \pi\,(r_{i+1/2}^2 - r_{i-1/2}^2)\,\Delta z, \\
  A^r_{i\pm1/2}  &= 2\pi\,r_{i\pm1/2}\,\Delta z, \\
  A^z_{j\pm1/2}  &= \pi\,(r_{i+1/2}^2 - r_{i-1/2}^2).
\end{align}
After cancellation of common $\pi\,\Delta z$ factors:
\begin{itemize}
  \item \textbf{$r$-direction:}
    \[
      \text{RHS}_r = \frac{2\,(r_{i-1/2}\,F^r_{i-1/2} - r_{i+1/2}\,F^r_{i+1/2})}
                          {r_{i+1/2}^2 - r_{i-1/2}^2}
    \]
  \item \textbf{$z$-direction:}
    \[
      \text{RHS}_z = \frac{F^z_{j-1/2} - F^z_{j+1/2}}{\Delta z}
      \qquad \text{(same as Cartesian)}
    \]
\end{itemize}

\subsection{Geometric Source Term}

The Euler equations in cylindrical coordinates have an additional source
in the radial momentum equation:
\[
  S_{r\text{-mom}} = +\frac{p}{r}
\]
This arises because the standard Cartesian-form momentum flux
$\rho u_r^2 + p$ is used on r-faces, but the divergence
$-\frac{1}{r}\frac{\partial(r F_r)}{\partial r}$ does not fully produce
the $p/r$ contribution when expanding the cylindrical form.

Additionally, the viscous stress tensor has extra hoop-stress terms not
captured by the face-flux divergence; these are handled by
\texttt{prob\_rhs.rz\_geometric\_source()}.

\section{Code Details}  \label{sec:divergence}

\subsection{\texttt{rz\_sanity\_check()} --- \texttt{CNS.h}}

Called once per level during \texttt{CNS} construction.  Checks:
\begin{enumerate}
  \item \texttt{AMREX\_SPACEDIM == 2}.
  \item $r$-direction is non-periodic.
  \item \texttt{prob\_lo[0] == 0} (axis at $r=0$).
\end{enumerate}

\subsection{Volume-Weighted \texttt{printTotal()} --- \texttt{CNS.cpp}}

The original code used \texttt{consmf.sum(comp) * geom.ProbSize()},
which is only correct for uniform Cartesian cells.  The new version:
\begin{enumerate}
  \item Creates a \texttt{volume} MultiFab via \texttt{geom.GetVolume()}.
  \item Uses \texttt{ReduceOps<ReduceOpSum>} to compute
        $\sum_i U_i \cdot V_i$ on GPU.
\end{enumerate}

\subsection{Flux Divergence Kernel --- \texttt{compute\_rhs.cpp}}

The divergence computation is now split into two branches at runtime:

\begin{lstlisting}[caption={Simplified RZ branch structure}]
const bool is_rz = geom.IsRZ();
if (is_rz) {
    // Cylindrical (r,z) finite-volume divergence
    ParallelFor(bx, [=] AMREX_GPU_DEVICE(int i, int j, int k) {
        Real r_lo = r0 + i * dr;
        Real r_hi = r_lo + dr;
        Real r2diff = (r_hi + r_lo) * dr;
        Real inv_r2diff = 1.0 / max(r2diff, tiny);
        Real inv_r = 1.0 / max(r_lo + 0.5*dr, tiny_r);

        for (int n = 0; n < ncons; ++n) {
            // r-direction: -(1/r) d(rF_r)/dr
            state(i,j,k,n) += 2*(r_lo*fx(i,j,k,n)
                               - r_hi*fx(i+1,j,k,n)) * inv_r2diff;
            // z-direction: Cartesian
            state(i,j,k,n) += (fy(i,j,k,n)
                               - fy(i,j+1,k,n)) * inv_dz;
            // Geometric source: +p/r for radial momentum
            if (n == umom_r)
                state(i,j,k,n) += prims(i,j,k,qpres) * inv_r;
        }
    });
} else {
    // Standard Cartesian divergence (1D/2D/3D via #if)
}
\end{lstlisting}

Key implementation details:
\begin{itemize}
  \item Uses a 3D \texttt{ParallelFor} with inner $n$-loop to reuse
        geometric metrics ($r_{\text{lo}}, r_{\text{hi}}, V^{-1}$)
        across all conserved components.
  \item A tiny positive floor prevents division by zero at $r=0$.
        In practice $r_0 = 0$ and $i \geq 0$ so $r_{1/2}^2 - r_{-1/2}^2 > 0$,
        but the floor guards against edge cases.
  \item After the divergence, \texttt{rz\_geometric\_source()} is called
        for viscous hoop-stress terms.
\end{itemize}

\section{Input File Configuration}
%==========================================================================

To enable RZ mode, add to the input file:
\begin{lstlisting}[language=bash,frame=single]
geometry.coord_sys = 1    # 0=Cartesian, 1=RZ
geometry.prob_lo   = 0.0 <z_lo>
geometry.prob_hi   = <r_hi> <z_hi>
geometry.is_periodic = 0 <z_periodic>
\end{lstlisting}
