\section{Scope}

This note documents the \textbf{current} IBM initialization path used by
\texttt{src/ibm/eib.h} with the custom BVH backend
(\texttt{bvh\_defs.h}, \texttt{bvh.h}, \texttt{eib\_bvh.h}).
It replaces earlier CGAL-centered startup descriptions.

\section{Entry Point and Call Chain}

At startup, the first IBM call is:
\begin{verbatim}
IBM::ib.init(&amr)
\end{verbatim}

The effective sequence is:
\begin{enumerate}[nosep]
  \item \texttt{eib\_t::init(Amr*)} in \texttt{eib.h}
  \item \texttt{read\_geom()} in \texttt{eib\_io.h}
  \item (later in AMR init/regrid hooks) \texttt{computeMarkers(lev)}
  \item \texttt{initialiseGPs(lev)}
\end{enumerate}

\section{Stage A: \texttt{init} (Level Metrics)}

\texttt{init} performs solver-level setup:
\begin{itemize}[nosep]
  \item stores \texttt{amr\_p} and refinement ratios,
  \item allocates per-level containers (\texttt{bmf\_a}, \texttt{faces\_per\_level}),
  \item computes per-level cell sizes \(\Delta x\), cell diagonal \(h\), and image-point distances:
  \[
  d^{\mathrm{GP}}_\ell = \alpha\,h_\ell,
  \qquad
  d^{\mathrm{surf}}_\ell = \alpha_{\mathrm{surf}}\,h_\ell.
  \]
  \item calls \texttt{read\_geom()}.
\end{itemize}

\section{Stage B: \texttt{read\_geom} (Geometry Load + BVH Build)}

Geometry filenames are read from:
\begin{verbatim}
ib.filename = ...
\end{verbatim}

For each geometry index \(i\):
\begin{enumerate}[nosep]
  \item Read geometry:
  \begin{itemize}[nosep]
    \item 2-D: \texttt{read\_polygon\_2d(files\_a[i], geom\_a[i], min\_dx)}
    \item 3-D: \texttt{read\_mesh(files\_a[i], geom\_a[i])}
  \end{itemize}
  \item Build BVH: \texttt{bvh\_a[i].build(geom\_a[i])}
  \item Construct inside/outside tester:
  \begin{itemize}[nosep]
    \item 2-D: \texttt{inside\_t(geom\_a[i], bvh\_a[i])}
    \item 3-D: \texttt{inside\_t(geom\_a[i], bvh\_a[i])}
  \end{itemize}
  \item Store bbox: \texttt{bbox\_a[i] = geom\_a[i].bbox()}
  \item Append flattened per-element cache:
  \begin{itemize}[nosep]
    \item \texttt{SurfElem\_a} (centroid + measure + geom id)
    \item \texttt{LocalFrame\_a} (normal/tangent basis)
    \item \texttt{geom\_offsets[i]} for global element indexing
  \end{itemize}
\end{enumerate}

After all geometries:
\begin{itemize}[nosep]
  \item validate cache sizes,
  \item run geometry consistency checks (intersection/containment),
  \item optionally flip normals if \texttt{interior\_is\_solid = false}.
\end{itemize}

\section{Stage C: \texttt{computeMarkers} (Solid/Ghost Classification)}

\texttt{computeMarkers(lev)} fills per-cell marker components:
\begin{itemize}[nosep]
  \item comp 0: fluid/solid id,
  \item comp 1: ghost-cell id.
\end{itemize}

Current implementation has GPU path under \texttt{AMREX\_USE\_GPU}:
\begin{enumerate}[nosep]
  \item Solid pass uses \texttt{InsideTesterView} in \texttt{ParallelFor}
        with bbox rejection.
  \item Ghost pass flags interface-adjacent solids.
  \item Prefix-sum based compaction extracts \texttt{gp\_ijk} list.
\end{enumerate}

\section{Stage D: \texttt{initialiseGPs} (Per-Ghost Geometry Metadata)}

For each ghost point:
\begin{enumerate}[nosep]
  \item determine owning geometry index,
  \item run BVH closest-point query to get IB foot point and primitive id,
  \item map primitive id to global face/edge index via \texttt{geom\_offsets},
  \item compute distance to boundary and local frame,
  \item place image points and build interpolation stencils/weights,
  \item store into \texttt{gpData\_t} SoA arrays.
\end{enumerate}

\section{Data Objects Produced by Initialization}

After Stage A--D, the main precomputed IBM state is:
\begin{itemize}[nosep]
  \item \texttt{geom\_a} : geometry containers,
  \item \texttt{bvh\_a} : per-geometry BVH trees,
  \item \texttt{inout\_fa} : inside/outside testers,
  \item \texttt{bbox\_a} : coarse geometry bboxes,
  \item \texttt{SurfElem\_a}, \texttt{LocalFrame\_a}, \texttt{geom\_offsets},
  \item per-FAB \texttt{IBMultiFab} marker data + \texttt{gpData\_t} payload.
\end{itemize}

These objects are then reused throughout RHS and surface post-processing.
